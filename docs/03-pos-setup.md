# ขั้นที่ 3: ติดตั้งหน้าขายที่คอมหน้าร้าน

ทำตามลำดับ ใช้เวลาประมาณ 45 นาที ข้อ 1 ทำที่ไหนก็ได้ ข้อ 2 เป็นต้นไปทำที่ร้าน

> ชื่อเมนูใน Windows และไดรเวอร์เครื่องพิมพ์แต่ละยี่ห้อต่างกันเล็กน้อย ถ้าหาไม่เจอ ถ่ายภาพหน้าจอส่งมาได้เลย

## 1. อัปเดตฐานข้อมูล (ต้องทำก่อน)

หน้าขายและหน้านำเข้า Excel ต้องใช้ฟังก์ชันชุดใหม่ รันไฟล์เหล่านี้ทีละไฟล์ตามลำดับ (ไฟล์ไหนรันแล้ว รันซ้ำได้ ไม่เสียหาย)

| ไฟล์ | ใช้กับ |
| --- | --- |
| [`supabase/002_pos.sql`](../supabase/002_pos.sql) | เปลี่ยน/คืน ยกเลิกบิล พิมพ์ซ้ำ โปรโมชัน |
| [`supabase/003_import.sql`](../supabase/003_import.sql) | นำเข้าสินค้าจาก Excel |
| [`supabase/004_delete.sql`](../supabase/004_delete.sql) | ลบสินค้า และลบสีไซซ์ |

วิธีรันแต่ละไฟล์

1. เปิดไฟล์ใน GitHub แล้วกด **Copy raw file**
2. ที่ Supabase เลือก **SQL Editor** > **New query** วางโค้ด แล้วกด **Run**
3. ขึ้น **Success** เป็นอันเสร็จ

## 2. เข้าหน้าขายด้วยบัญชีเครื่อง POS

1. ที่คอมหน้าร้าน เปิด **Microsoft Edge** ไปที่ `https://meesin-pos.latemek2.workers.dev`
2. เข้าสู่ระบบด้วย **บัญชีเครื่อง POS** (อีเมลที่มี `+pos`) ไม่ใช่บัญชีพี่สาว
   - บัญชีเครื่อง POS ขายได้แต่ไม่เห็นต้นทุนและแก้สินค้าไม่ได้ ปลอดภัยกว่าถ้าลืมล็อกหน้าจอ
3. ใส่ PIN เข้า POS แล้วจะเจอหน้า **เปิดร้าน**

ระบบจำการเข้าสู่ระบบไว้ ครั้งต่อไปใช้แค่ PIN

## 3. เครื่องสแกนบาร์โค้ด

1. เสียบสาย USB ไม่ต้องลงโปรแกรม
2. เปิด Notepad แล้วลองยิงบาร์โค้ดสินค้า ต้องขึ้นตัวเลขแล้ว **ขึ้นบรรทัดใหม่เอง**
3. ถ้าไม่ขึ้นบรรทัดใหม่ เปิดคู่มือที่มากับเครื่องสแกน หาบาร์โค้ดตั้งค่าชื่อ **Add CR suffix** หรือ **Enter suffix** แล้วยิงบาร์โค้ดนั้นหนึ่งครั้ง

ในหน้าขาย ยิงได้ทันทีโดยไม่ต้องคลิกช่องค้นหา

## 4. เครื่องพิมพ์ใบเสร็จ 80 มม. และลิ้นชัก

1. ติดตั้งไดรเวอร์ Windows ของเครื่องพิมพ์ (ดาวน์โหลดจากเว็บยี่ห้อนั้น หรือแผ่นที่มากับเครื่อง)
2. **Settings > Bluetooth & devices > Printers & scanners** เลือกเครื่องพิมพ์ใบเสร็จ แล้วกด **Set as default**
   - ปิด **Let Windows manage my default printer** ก่อน ไม่อย่างนั้นปุ่มนี้จะไม่ขึ้น
3. เข้า **Printing preferences** ของเครื่องพิมพ์ ตั้งขนาดกระดาษเป็น **80 mm** (บางรุ่นเรียก Roll Paper 80 x 297 mm)
4. **ลิ้นชักเก็บเงิน** ต่อสาย RJ11 เข้าเครื่องพิมพ์ แล้วในไดรเวอร์หาหัวข้อ **Cash Drawer** หรือ **Peripheral** ตั้งให้เปิดลิ้นชักเมื่อพิมพ์
5. ทดสอบ: ในหน้าขายกด **พิมพ์ซ้ำ** ใส่เลขบิลใดก็ได้ แล้วกด **พิมพ์สำเนา** หน้าต่างพิมพ์ของ Edge จะขึ้น ตั้งค่าดังนี้แล้วกดพิมพ์ 1 ครั้ง
   - **Printer:** เครื่องพิมพ์ใบเสร็จ
   - **Margins:** None
   - **Scale:** 100
   - **Headers and footers:** ไม่ติ๊ก

## 5. ให้พิมพ์ใบเสร็จทันทีโดยไม่ถามทุกครั้ง

ปกติเบราว์เซอร์จะถามก่อนพิมพ์ทุกครั้ง ทำทางลัดพิเศษเพื่อให้พิมพ์ทันที

1. ปิดหน้าต่าง Edge **ทุกหน้าต่าง**
2. Edge > **Settings > System and performance** ปิดสองข้อนี้
   - **Startup boost**
   - **Continue running background extensions and apps when Microsoft Edge is closed**
3. คลิกขวาที่หน้าจอ Desktop > **New > Shortcut** ช่อง location วางข้อความนี้ทั้งบรรทัด

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing --start-fullscreen --app=https://meesin-pos.latemek2.workers.dev/pos
   ```

4. ตั้งชื่อทางลัดว่า `มีศิลป์ POS` แล้วกด **Finish**
5. เปิดหน้าขายจากทางลัดนี้ทุกครั้ง ใบเสร็จจะออกที่เครื่องพิมพ์ทันทีหลังรับเงิน
   - ออกจากโหมดเต็มจอกด **F11**
   - ถ้ายังมีหน้าต่างถามก่อนพิมพ์ แปลว่ามี Edge เปิดค้างอยู่ ปิดให้หมดหรือรีสตาร์ทเครื่องแล้วเปิดจากทางลัดใหม่

ถ้าอยากให้เปิดเองตอนเปิดเครื่อง กด `Win + R` พิมพ์ `shell:startup` แล้วคัดลอกทางลัดไปวางในโฟลเดอร์ที่เปิดขึ้นมา

## 6. ทดสอบก่อนใช้จริง

ทำครบทุกข้อ ระหว่างทดสอบสต็อกจะลดจริง ทดสอบเสร็จแล้วให้ **ยกเลิกบิลทดสอบทุกใบ** สต็อกจะกลับคืนเอง และบิลที่ยกเลิกไม่นับในยอดขาย

- [ ] เปลี่ยน PIN เริ่มต้นทั้งสองตัวที่หลังบ้าน > ตั้งค่า (เข้า POS `1234` / อนุมัติ `0000`)
- [ ] ใส่เลขพร้อมเพย์ และเลขบัญชีรับโอนที่หลังบ้าน > ตั้งค่า
- [ ] **สแกน QR พร้อมเพย์ด้วยแอปธนาคารจริง** ดูว่าชื่อบัญชีที่ขึ้นเป็นของร้าน และยอดเงินถูกต้อง (ไม่ต้องกดโอน)
- [ ] ขายเงินสด ใบเสร็จออก ลิ้นชักเปิด
- [ ] ขายแบบให้ส่วนลด ระบบถาม PIN อนุมัติ
- [ ] พักบิล แล้วเรียกกลับมา
- [ ] สมัครสมาชิก ขาย แล้วดูแต้มบนใบเสร็จ
- [ ] เปลี่ยนไซซ์จากบิลเดิม
- [ ] ยกเลิกบิล
- [ ] ปิดยอด นับเงิน และพิมพ์ใบสรุป

## งานประจำวันที่ร้าน

| ช่วง | ทำอะไร |
| --- | --- |
| เปิดร้าน | เปิดทางลัด `มีศิลป์ POS` ใส่ PIN ใส่เงินทอนตั้งต้น |
| ระหว่างวัน | ขาย เช็กสต็อก เปลี่ยน/คืน กด **ล็อก** ทุกครั้งที่ลุกจากเคาน์เตอร์ |
| ปิดร้าน | **ปิดยอด** นับแบงก์และเหรียญ ใบสรุปจะพิมพ์ออกมา เก็บไว้กับเงิน |

## เมื่อระบบมีเวอร์ชันใหม่

มุมซ้ายล่างจะขึ้นแถบ **มีระบบเวอร์ชันใหม่** กด **อัปเดตเลย** ตอนไม่มีบิลค้างอยู่ หน้าจอจะโหลดใหม่เป็นเวอร์ชันล่าสุด

ถ้ายังไม่มีแถบนี้ แต่รู้ว่ามีการแก้ระบบแล้ว กด `Ctrl + Shift + R` เพื่อโหลดหน้าใหม่ทั้งหมด

## ถ้าอินเทอร์เน็ตหลุด

หน้าขายต้องใช้อินเทอร์เน็ตตอนบันทึกบิล ถ้าเน็ตหลุดให้จดบิลลงสมุดก่อน (สินค้า สี ไซซ์ ราคา วิธีชำระ) แล้วคีย์ขายย้อนหลังเมื่อเน็ตกลับมา
