# ขั้นที่ 1: ตั้งค่าฐานข้อมูล Supabase

ใช้เวลาประมาณ 20 นาที ทำครั้งเดียว ทำบนคอมของคุณได้เลย ไม่ต้องอยู่ที่ร้าน

> ชื่อปุ่มและเมนูของ Supabase อาจต่างจากในคู่มือเล็กน้อย เพราะเขาปรับหน้าเว็บบ่อย ถ้าหาไม่เจอ ถ่ายภาพหน้าจอส่งมาได้เลย

---

## 1. สมัคร Supabase

1. เข้า https://supabase.com แล้วกด **Start your project**
2. เลือก **Continue with GitHub** แล้วเข้าด้วยบัญชี `latemek2`
3. ถ้าถูกถามให้สร้าง Organization ให้ตั้งชื่ออะไรก็ได้ เช่น `meesin` และเลือกแพ็กเกจ **Free**

## 2. สร้างโปรเจกต์

1. กด **New project**
2. กรอกดังนี้
   - **Name:** `meesin-pos`
   - **Database Password:** กด **Generate a password** แล้ว **คัดลอกไปเก็บไว้ในที่ปลอดภัย** (ห้ามส่งให้ใคร รวมถึงในแชตนี้)
   - **Region:** `Southeast Asia (Singapore)` เพราะใกล้ไทยที่สุด ระบบจะเร็วกว่า
3. กด **Create new project** แล้วรอประมาณ 2 นาที

## 3. สร้างตารางทั้งหมดด้วยไฟล์ SQL

1. เปิดไฟล์ [`supabase/001_setup.sql`](../supabase/001_setup.sql) ใน GitHub แล้วกดปุ่ม **Copy raw file** (ไอคอนรูปเอกสารซ้อนกัน มุมขวาบนของไฟล์)
2. กลับไปที่ Supabase เมนูซ้าย เลือก **SQL Editor**
3. กด **New query** แล้ววาง (Ctrl+V) โค้ดทั้งหมดลงไป
4. กด **Run** (หรือ Ctrl+Enter)
5. ถ้าสำเร็จจะขึ้นว่า **Success. No rows returned**

ถ้าขึ้นหน้าต่างเตือนเรื่อง "destructive operation" ให้กด **Run this query** ได้ เพราะไฟล์นี้มีคำสั่งปิดสิทธิ์บางอย่างเพื่อความปลอดภัย

## 4. สร้างบัญชีผู้ใช้ 2 บัญชี

ระบบมีผู้ใช้ 2 แบบ

| บัญชี | ใช้ทำอะไร | ตัวอย่างอีเมล |
| --- | --- | --- |
| เจ้าของร้าน | เข้าหลังบ้าน สิทธิ์เต็ม | อีเมลจริงของพี่สาว |
| เครื่อง POS | ล็อกอินค้างไว้ที่คอมหน้าร้าน ขายได้ แต่แก้สินค้าและดูต้นทุนไม่ได้ | อีเมลพี่สาวเติม `+pos` เช่น `meesin+pos@gmail.com` |

> Gmail ส่งอีเมลที่มี `+อะไรก็ได้` เข้ากล่องเดิม จึงใช้อีเมลเดียวทำสองบัญชีได้

ทำแบบนี้ 2 รอบ (รอบละบัญชี)

1. เมนูซ้าย เลือก **Authentication** แล้วเลือก **Users**
2. กด **Add user** แล้วเลือก **Create new user**
3. ใส่อีเมลและรหัสผ่าน (ตั้งรหัสผ่านยาวอย่างน้อย 10 ตัว แล้วจดเก็บไว้)
4. ติ๊ก **Auto Confirm User**
5. กด **Create user**

## 5. กำหนดว่าบัญชีไหนเป็นเจ้าของร้าน บัญชีไหนเป็นเครื่อง POS

1. กลับไปที่ **SQL Editor** แล้วกด **New query**
2. วางโค้ดนี้ **แล้วแก้อีเมลสองจุดให้ตรงกับที่สร้างไว้**

```sql
insert into public.profiles (user_id, role, display_name)
select id, 'owner', 'พี่สาว' from auth.users where email = 'ใส่อีเมลเจ้าของร้าน';

insert into public.profiles (user_id, role, display_name)
select id, 'pos', 'เครื่องหน้าร้าน' from auth.users where email = 'ใส่อีเมลเครื่อง POS';

select p.role, u.email from public.profiles p join auth.users u on u.id = p.user_id;
```

3. กด **Run** ตารางผลลัพธ์ต้องมี **2 แถว** คือ `owner` และ `pos` ถ้ามีแถวเดียว แปลว่าพิมพ์อีเมลไม่ตรง แก้แล้ว Run เฉพาะบรรทัดของบัญชีที่ขาดใหม่

## 6. ปิดการสมัครสมาชิกเอง

กันไม่ให้คนนอกสมัครบัญชีเข้ามาเอง (ถึงสมัครได้ก็จะไม่มีสิทธิ์เห็นอะไร แต่ปิดไว้ปลอดภัยกว่า)

1. **Authentication** แล้วหาเมนู **Sign In / Providers** (หรือ **Providers**)
2. ปิดสวิตช์ **Allow new users to sign up**
3. กด **Save**

## 7. ส่งค่าเชื่อมต่อมาให้ผม

1. เมนูซ้ายล่าง เลือก **Project Settings** แล้วเลือก **API** (หรือ **Data API** และ **API Keys**)
2. คัดลอก 2 ค่านี้ส่งมาในแชต
   - **Project URL** หน้าตาแบบ `https://xxxxxxxx.supabase.co`
   - **anon public** key หรือ **Publishable key** (ขึ้นต้นด้วย `eyJ...` หรือ `sb_publishable_...`)

ค่า 2 ค่านี้ออกแบบมาให้ใส่ในหน้าเว็บได้ จึงส่งในแชตได้ ความปลอดภัยจริงอยู่ที่กฎในฐานข้อมูลที่ติดตั้งไปในข้อ 3

> **ห้ามส่ง** `service_role` key, `secret` key หรือ Database Password ให้ใครเด็ดขาด สองอย่างนี้เปิดประตูหลังบ้านได้ทั้งหมด
