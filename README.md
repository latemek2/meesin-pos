# มีศิลป์ POS

ระบบขายหน้าร้านและหลังบ้านของร้านมีศิลป์ (รองเท้าและเสื้อผ้า) ใช้ฐานข้อมูลชุดเดียวกัน

- **POS หน้าร้าน (`/pos`)** ติดตั้งเป็นแอปบนคอม Windows จอสัมผัส ใช้ขาย เช็กสต็อก พักบิล เปลี่ยนหรือคืนสินค้า ยกเลิกบิล และปิดยอด
- **หลังบ้าน (`/admin`)** สำหรับเจ้าของร้าน จัดการสินค้า สีและไซซ์ บาร์โค้ด รับของเข้า นับสต็อก สมาชิก โปรโมชัน และรายงาน

## ความคืบหน้า

| ขั้น | สถานะ |
| --- | --- |
| ฐานข้อมูล กฎความปลอดภัย ฟังก์ชันการขาย | เสร็จ ผ่านการทดสอบ 53 กรณี |
| คู่มือตั้งค่า Supabase | เสร็จ |
| หลังบ้าน: สินค้า สีไซซ์ สต็อกตั้งต้น ปรับสต็อก | เสร็จ |
| หลังบ้าน: ซัพพลายเออร์ รับของเข้า พิมพ์สติกเกอร์ ตั้งค่า PIN | เสร็จ |
| คู่มือขึ้นเว็บด้วย Cloudflare | เสร็จ |
| POS หน้าร้าน: ขาย เช็กสต็อก สมาชิก ส่วนลด พักบิล ชำระ 5 วิธี QR พร้อมเพย์ ใบเสร็จ เปลี่ยน/คืน ยกเลิก ปิดยอด | เสร็จ |
| คู่มือติดตั้งหน้าร้าน | เสร็จ |
| หลังบ้าน: นับสต็อก บิลขาย สมาชิก โปรโมชัน รายงาน | กำลังทำ |

## โครงสร้างโปรเจกต์

```
src/
  admin/               หน้าหลังบ้าน
  pos/                 หน้าขาย
  components/          ส่วนประกอบที่ใช้ร่วมกัน
  lib/                 เชื่อมต่อฐานข้อมูล ไซซ์ รูปแบบตัวเลข
supabase/
  001_setup.sql        ตาราง กฎความปลอดภัย ฟังก์ชัน และข้อมูลเริ่มต้น
  002_pos.sql          ค้นบิล และตรวจส่วนลดโปรโมชัน สำหรับหน้าขาย
  tests/db.test.mjs    ทดสอบการขาย เปลี่ยนคืน ยกเลิก ปิดยอด และสิทธิ์ บนฐานข้อมูลจำลอง
docs/                  คู่มือภาษาไทย
```

## สำหรับนักพัฒนา

```
npm install
npm run dev        เปิดทดสอบในเครื่อง
npm run build      สร้างไฟล์สำหรับขึ้นเว็บ
npm run test:db    ทดสอบฐานข้อมูลบน Postgres จำลอง
```

## หลักการสำคัญของฐานข้อมูล

- **สต็อกเก็บเป็นประวัติ:** ทุกการขาย รับของ คืน นับ เป็นหนึ่งแถวใน `stock_movements` ยอดคงเหลือคำนวณจากประวัตินี้ ติดลบได้
- **บันทึกบิลรวดเดียว:** `create_sale` บันทึกบิล รายการ ตัดสต็อก และแต้ม พร้อมกัน ถ้าขั้นใดผิด ทุกอย่างถูกยกเลิก
- **เครื่อง POS มองไม่เห็นต้นทุน:** ต้นทุนอยู่ในตารางแยกที่เปิดให้เจ้าของร้านเท่านั้น
- **ไม่มีการลบบิล:** ยกเลิกได้ด้วย PIN เจ้าของร้าน บิลยังอยู่โดยมีสถานะยกเลิก
